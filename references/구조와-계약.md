# 구조와 계약 (유지보수용)

이 문서는 도구(`scripts/`)와 엔진(`assets/engine/`)이 서로 지키는 약속이다. 활동지를 만드는 에이전트는 읽지 않아도 된다. 스킬 자체를 고칠 때, 그리고 처음 구현할 때의 기준이다. 약속을 바꾸면 이 문서를 함께 고친다.

## 0. 목표와 기준

- 산출물은 **A4 세로 인쇄용 학생 활동지**를 담은 HTML 한 파일이다. 인터넷 없이 열리고(글꼴·그림·엔진 모두 내장), 브라우저에서 인쇄·PDF 저장 시 화면과 같은 쪽으로 나온다.
- 한 번 조립하면 두 파일이 나온다. **교사용**(`<제목> (교사용).html`)은 정답·예시 답안·교사용 메모·풀이 쪽을 담은 편집 원본이고, **학생용**(`<제목>.html`)은 교사용에서 정답과 교사 전용 요소를 **물리적으로 지운** 배부본이다. 학생용 파일의 소스 보기로도 정답을 찾을 수 없어야 한다.
- 지면 수치는 사용자의 HWPX 정본(`pbj-worksheet-hwpx`의 활동지 조판 기준)을 따른다. 요약은 [지면 기준](지면-기준.md).
- 외부 자원(웹 글꼴·CDN·원격 그림)을 쓰지 않는다. 애니메이션은 쓸 일이 거의 없고, 쓰더라도 `prefers-reduced-motion`으로 끄는 코드를 넣지 않는다.

## 2. 명령

`python -X utf8 "<스킬>/scripts/sheet.py" <명령>`. 종료 코드: 0 통과, 1 고칠 것 있음, 2 도구 실패. 모든 메시지는 한국어, 다음에 할 일을 한 줄로 알린다.

| 명령 | 하는 일 |
| --- | --- |
| `new "<폴더>" --title "…" [--kind 수업\|연습\|평가] [--columns 1\|2]` | 폴더·`그림/`·`구성.json`(틀) 생성. 이미 있으면 멈춤 |
| `blocks [<종류>]` | 블록 목록 / 한 블록의 필드·한도·바로 쓸 JSON 조각 |
| `plan "<폴더>"` | `구성.json` 검증(4절). 오류·경고를 JSON 경로와 함께 출력 |
| `build "<폴더>" [--force]` | plan 통과 후 교사용·학생용 HTML 생성, `검사/build.json` 기록. 편집기로 저장된 교사용 파일을 덮어쓰려 하면 멈춤(`--force`로만) |
| `derive "<교사용.html>"` | 교사용 HTML에서 학생용 HTML을 다시 만든다(브라우저에서 고친 뒤 쓰는 길) |
| `check "<폴더>"` | 실제 브라우저로 두 파일을 열어 검사, PDF·쪽 그림·모아보기·report.json 생성(7절) |
| `status "<폴더>"` | 관문별 ✓/✗와 다음 할 일(8절) |

필요 환경: Python 3.9 이상. 선택: fontTools(글꼴 내장), Pillow(그림 줄이기·모아보기), PyMuPDF(PDF→PNG). 없으면 해당 기능을 건너뛰거나 대체 경로로 진행하고 경고한다. `check`는 Chrome 또는 Edge가 필요하다(`SHEET_BROWSER`로 지정 가능).

## 3. 구성.json

```json
{
  "version": 1,
  "meta": {
    "title": "두 대여소의 요금 비교",
    "kind": "수업",
    "columns": 1,
    "subject": "수학",
    "grade": "1학년",
    "term": "2026학년도 1학기",
    "unit": "일차방정식의 활용",
    "header_title": null,
    "name_fields": ["반", "번", "이름"],
    "pair": false,
    "total_points": null,
    "goal": "학생이 마지막에 무엇을 쓰거나 판단하는지 한 문장 (화면에 안 나옴)"
  },
  "items": [
    { "id": "q1", "break": false, "blocks": [ { "type": "situation", "...": "..." } ] }
  ],
  "teacher": {
    "memo": ["배부: A4 한 장 양면", "인쇄: 실제 크기(100%)"],
    "solutions": [
      { "item": "q1", "answer": "…", "steps": ["…"], "rubric": ["…"], "alternatives": ["…"], "misconceptions": ["…"] }
    ]
  }
}
```

- `meta.kind`: `수업`(수업 활동지, 기본) · `연습`(연습지, 정본 B) · `평가`(수행평가지, 정본 A). 머리표 모양, 라벨 열 너비, 채우기 색 허용 여부가 달라진다.
- `meta.columns`: 1 또는 2. 2단은 `수업`에서만 허용(참고 C).
- 머리표는 `meta`로 자동 생성되어 문서 맨 앞 item(`id: "head"`)이 된다. 직접 `header` 블록을 쓰지 않는다. 두 장 배부의 2장 머리에는 `nameband` 블록을 쓴다.
- `items[]`는 **함께 있어야 하는 묶음**이다(보통 한 문항 = 상황 + 발문 + 답안표). 한 item은 쪽(2단이면 단)을 넘지 않는다. `break: true`면 새 쪽(2단이면 새 단)에서 시작한다. `id`는 영문·숫자·`-`로 문서 안에서 유일하다.
- `teacher`는 교사용 파일에만 들어간다. `solutions[].item`은 items의 id.

### 3.1 글자 필드의 표기(인라인 표기)

모든 글자 필드(발문·상황 문장·라벨·안내·표 칸·캡션·선택지·정답)는 같은 표기를 쓴다. 필드 하나는 한 문단이며 줄바꿈 문자를 넣지 않는다(여러 문단은 배열).

| 표기 | 뜻 | 학생용 | 교사용 |
| --- | --- | --- | --- |
| `$…$` | 수식. 문법은 pbj-html-deck과 같다(`\frac` `\sqrt` `^{}` `_{}` `\times` `\le` `\angle` `\overline{AB}` `\text{cm}` …). 소문자는 기울임, 대문자는 정체, `-`는 `−` | MathML | MathML |
| `{{㉠}}` | 기호가 있는 빈칸 | 밑줄 친 `  ㉠  ` | 같은 모양 |
| `{{㉠\|꼬인 위치}}` | 기호 + 정답 | 밑줄 친 `  ㉠  ` | 밑줄 위에 정답(빨강) |
| `{{\|3}}` | 기호 없는 빈칸 + 정답 | 밑줄 빈칸(정답 길이에 맞춘 너비, 최소 18mm) | 밑줄 위에 정답 |
| `{{\|3\|30}}` | 너비 30mm 지정 | 30mm 밑줄 빈칸 | 〃 |
| `**굵게**` | 굵은 글씨 | | |

- 밑줄 문자(`___`)로 빈칸을 만들지 않는다(plan 오류).
- 빈칸 기호는 `㉠㉡㉢…` 순서로 문서 전체에서 이어진다(plan 검사).
- 정답 칸(`{{…|정답}}`의 정답, 답안표 `answer`)도 같은 표기를 쓴다.

### 3.2 블록 종류

`assets/kit/blocks.json`이 정본이다. 아래는 필드의 뜻이다. 글자 수 한도는 등록부에 둔다.

| type | 필드 | 모양(정본 근거) |
| --- | --- | --- |
| `notice` | `label`(예: "평가 안내"), `lines[]` | 라벨 열 25mm + 안내 글 표. 1장 첫머리 안내(조판 7.1) |
| `nameband` | `label`(예: "작도 활용 문제 해결 · 2장") | 두 장 배부 때 2장 머리의 이름 띠(60 \| 128mm) |
| `situation` | `title`(선택, 예: "<상황>"), `lines[]`(문단 배열, 대화는 `화자 : 발화`), `figure`(선택, 4.1의 그림 객체), `note`(선택, 오른쪽 정렬 낱말 풀이) | 그림이 있으면 1행×2열(글 64~69% : 그림 31~36%), 없으면 1×1 상자(조판 7.2) |
| `question` | `text`, `number`(기본 true; false면 번호 없는 안내 발문) | `1. 발문` 한 문단. 번호는 자동으로 1부터(조판 7.4) |
| `answer` | `rows[]`: `{mark?, label, points?, guide?, lines?, grow?, kind?, height_mm?, answer, group?}` | 라벨 열 + 답 칸 표(조판 7.5·7.6) |
| `steps` | `columns[]`(예: ["사용한 도구", "설명"]), `rows`(행 수), `answers[][]`(행별 정답), `lines?` | 번호(①②…)만 붙은 단계 기록 표 |
| `choices` | `options[]`, `answer`(1부터 시작하는 번호 또는 번호 배열), `cols?`(한 줄 개수) | ①②③④⑤ 선택지. 교사용은 정답 번호에 동그라미 |
| `table` | `header[]`, `rows[][]`(칸에 `{{…}}` 빈칸 가능), `widths_mm?` | 자료표/채우기 표 |
| `figure` | 4.1의 그림 객체 하나 + `caption?` | 가운데 정렬 그림 한 장 |
| `figures` | `items[]`(그림 객체 2개, 각 `caption`) | 2×2 표로 나란히(조판 7.2) |
| `grid` | 4.2 | 모눈·좌표평면(계산으로 그린 SVG) |
| `ask` | `tag`(예: "<질문 1-1>"), `text`, `lines`, `grow?`, `answer` | 수업 2단형 질문 상자(제목 줄 + 답 칸, 참고 C) |
| `text` | `text` | 일반 문단(정리 문장 등). 남용하지 않는다 |

`answer.rows[]`:

- `mark`: `㉠` 같은 빈칸 기호(같은 item의 상황·발문에 쓴 기호와 맞춘다).
- `label`: 채점 요소 이름. `points`: 배점(라벨 칸 안 `(2점)`으로 표시, 발문 끝에 붙이지 않음).
- `guide`: 라벨 칸 속 쓰기 안내(9pt).
- `lines`: 답 칸 빈 줄 수(2~30). 높이 = `5.64 × lines − 1.1` mm(본문 10pt·160% 기준). 기본 3.
- `grow`: true면 쪽에 남는 높이를 이 칸이 나눠 받는다(서술 칸에 쓴다).
- `kind`: `text`(기본) · `draw`(그리기·작도 칸, `height_mm` 필수, 줄 수 대신 높이).
- `answer`: 교사용 예시 답안(학생이 실제로 쓸 분량). `draw`는 그릴 내용 설명 또는 4.1의 그림 객체.
- `group`: 같은 채점 요소를 여러 행으로 나눌 때 같은 문자열을 준다. 연속된 같은 group 행은 라벨 칸을 세로로 합치고 `label`·`points`는 첫 행 것을 쓴다.

### 3.3 그림 객체(4.1)와 모눈(4.2)

그림 객체: `{"src": "그림/radar.png", "width_mm": 55, "alt": "…"}` 또는 `{"svg": "<svg …>…</svg>", "width_mm": 80}`. `src`는 `<폴더>` 기준 로컬 경로만. `teacher_only: true`면 교사용에만.

모눈 `grid`:

```json
{ "type": "grid", "mode": "coord", "x": [-5, 5], "y": [-5, 5], "unit_mm": 6,
  "labels": true,
  "draw": [ { "fn": "2*x+1", "teacher": true }, { "points": [[1, 3], [-2, -3]], "on": 0, "names": ["A", "B"], "teacher": false } ] }
```

- `mode`: `coord`(축·눈금·원점 O) 또는 `square`(모눈만, `cols`·`rows`·`unit_mm`).
- `draw[].fn`: x의 식(`+ - * / **`, 괄호, 수, `x`만). `teacher: true`면 교사용에만 그린다.
- `draw[].points`와 `on`(같은 draw 목록의 fn 번호): plan이 점이 그 그래프 위에 있는지 계산으로 확인한다.
- 선: 모눈 0.1mm 회색(#999), 축 0.3mm 검정. 그림 크기는 실제 mm.

## 4. plan 검증

오류(종료 1):

- 필수 필드·형식·알 수 없는 type·id 중복·`columns: 2`인데 `kind`가 수업이 아님.
- 수식 문법 오류, 줄바꿈 문자, 밑줄 문자 빈칸(`__` 이상), 외부 URL, 없는 그림 파일.
- **학생이 채울 모든 자리에 교사용 정답이 없음**: `answer` 행의 `answer`, `{{…}}` 빈칸의 정답, `choices.answer`, `steps.answers`, `ask.answer`, `table` 빈칸 정답.
- `lines`가 2~30 밖, `draw`인데 `height_mm` 없음.
- 빈칸 기호가 문서 순서대로 이어지지 않음(㉠ 다음 ㉢ 등).
- `meta.total_points`가 있는데 배점 합이 다름.
- `grid`의 점이 `on`으로 지정한 그래프 위에 있지 않음(1e-9 허용).

경고(종료 0, 출력만):

- 글자 수 한도 초과(등록부), 번호처럼 보이는 발문 시작(`1.`), 점검 줄(`□`) 사용.
- 수식 밖의 영문 대문자 낱말(점 이름을 평문으로 쓴 것 같음).
- 번호 있는 발문인데 `teacher.solutions`에 그 item이 없음.
- 답안표 행의 `mark`가 같은 item의 상황·발문 빈칸에 없음.

## 5. 조립된 HTML(DOM 계약)

```html
<!doctype html>
<html lang="ko" data-sheet="1" data-role="teacher" data-kind="수업" data-columns="1" data-answers="on">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>두 대여소의 요금 비교</title>
  <meta name="sheet-build" content='{"tool":"pbj-html-sheet","version":1,"built_at":"…","source_sha256":"…"}'>
  <style id="sheet-fonts">@font-face{…}</style>
  <style id="sheet-css">/* assets/engine/sheet.css 그대로 */</style>
  <style id="sheet-user">/* 편집기가 쓰는 덮어쓰기(:root 변수) */</style>
</head>
<body>
  <div id="sheet-src">
    <section class="ws-item" data-id="head" data-span="all">…머리표…</section>
    <section class="ws-item" data-id="q1">…블록들…</section>
    <section class="ws-item" data-id="q2" data-break="1">…</section>
  </div>
  <div id="sheet-teacher" class="ws-teacher-only">
    <section class="ws-item" data-id="t-memo">…교사용 메모…</section>
    <section class="ws-item" data-id="t-q1">…1번 풀이…</section>
  </div>
  <script id="sheet-js">/* assets/engine/sheet.js 그대로 */</script>
</body>
</html>
```

- 학생용은 `data-role="student"`, `data-answers` 없음, `#sheet-teacher` 없음.
- 저장된 파일에는 `#sheet-src`(평평한 원본)만 있고 쪽 틀은 없다. 엔진이 열 때마다 쪽을 짠다.
- 편집기로 저장하면 `<html>`에 `data-saved-at="ISO 시각"`이 붙는다(build의 덮어쓰기 보호에 쓴다).

### 5.1 정답과 교사 전용 표시

| 표시 | 뜻 | 학생용에서 |

| `.ws-key` | 정답·예시 답안 내용(빈칸 정답, 답 칸 예시, 모눈의 교사용 그래프 `<g class="ws-key">`) | 요소째 삭제 |

## 6. 엔진(sheet.js) 동작

### 6.1 쪽 짜기

1. `document.fonts.ready` 뒤에 시작한다. 준비 전에는 `#sheet-src`를 숨긴다.
2. `<main id="sheet-pages">`를 만들고 `.ws-page`(210×297mm) > `.ws-page-in`(여백) > 칸(slot)을 둔다. 1단은 쪽마다 `.ws-slot` 1개, 2단은 `.ws-top`(data-span="all" item 자리, 1쪽만) + `.ws-cols` > `.ws-slot` 2개(왼쪽 단, 오른쪽 단).
3. item을 순서대로 **옮겨 담는다**(복제하지 않는다). 남은 높이에 안 들어가면 다음 칸. `data-break="1"`이면 새 칸(1단: 새 쪽). item 사이 간격은 기본 8.2mm, 그 칸에서 넘칠 때만 4.7mm로 줄여 다시 맞춰 본다. 빈 칸에도 안 들어가는 item은 그 칸에 넣고 `too-tall`로 표시한다.
4. **답 칸 높이**: `data-lines` → `5.64 × n − 1.1`mm(본문 크기 배율을 곱한다), `data-kind="draw"` → `data-height-mm`. 인라인 `style.height`로 준다.
5. **늘이기**: 쪽을 다 짠 뒤 칸마다 `남는 높이 = 칸 높이 × 0.985 − 쓴 높이`를 `data-grow` 칸들에 기본 높이 비율로 나눠 더한다(`data-extra-mm`). 다시 재서 넘치면 비율을 줄인다. 교사 쪽은 늘이지 않는다.
6. 교사용(`data-role="teacher"`)이면 `#sheet-teacher`의 item을 학생 쪽 뒤에 이어지는 교사 쪽(`.ws-page.ws-tpage`)에 같은 방식으로 담는다(늘이기 없음). `data-answers`가 꺼져 있으면 교사 쪽을 숨긴다.
7. 발문 번호(`.ws-qn`)와 빈칸 기호 표시는 문서 순서로 다시 매긴다(편집으로 순서가 바뀌어도 맞게). 기호는 `data-mark`가 원본이다.
8. 화면에서는 쪽마다 바깥에 `1쪽 · 98%` 표시(넘치면 빨강). 인쇄에서는 숨긴다.

### 6.2 인쇄

- `@page { size: A4 portrait; margin: 0 }`. `.ws-page`는 정확히 210×297mm, `break-after: page`, `overflow: hidden`. 도구 막대·쪽 표시·편집 표시는 인쇄에서 숨긴다.
- 색은 `print-color-adjust: exact`. 화면 배경은 회색, 쪽은 흰색 그림자.

### 6.3 편집기(교사용 파일만)

- 위쪽 도구 막대(화면 전용): `편집`(E) · `정답 보기`(A, 켜고 끔) · `인쇄`(Ctrl+P) · `저장`(Ctrl+S) · `학생용으로 저장` · 글자 크기(본문 −/+, 발문 −/+, 5% 단위) · `글꼴`(기본: 바탕·맑은 고딕 계열 / 모두 고딕 / 파일에서 추가) · `되돌리기`(Ctrl+Z).
- 편집 모드:
  - 글자: `data-src`가 있는 요소를 두 번 누르면 원본 표기가 보이는 한 줄 입력 상태가 되고, Enter로 확정(3.1 표기를 JS로 다시 렌더), Esc로 취소. 수식·빈칸 표기도 그대로 고친다. 확정하면 쪽을 다시 짠다.
  - item: 마우스를 올리면 작은 막대 — `↑` `↓`(순서), `새 쪽에서`(data-break 켜고 끔), `복제`, `삭제`.
  - 답 칸: 작은 막대 — `줄 −` `줄 +`(data-lines, 2~30), `늘이기`(data-grow 켜고 끔), 그리기 칸은 `높이 −5mm` `+5mm`.
- 저장(Ctrl+S): 쪽에서 item을 꺼내 `#sheet-src`·`#sheet-teacher`에 원래 순서로 되돌리고, 실행 중 붙인 것(쪽 틀, 인라인 높이, `data-extra-mm`, 편집 표시, contenteditable)을 지운 문서를 저장한다. `showSaveFilePicker`로 처음 한 번 고르면 그 파일에 계속 저장하고, 안 되면 내려받기. `data-saved-at` 기록. pbj-html-deck의 `deck.js` 저장 방식을 참고한다.
- 학생용으로 저장: 같은 직렬화에 5.1 지우기를 적용하고 `data-role="student"`로 바꿔 `<제목>.html`로 저장.
- 글꼴 추가: 고른 파일을 base64로 `#sheet-fonts`에 `@font-face`로 넣고 역할(제목·발문·본문)에 지정. 저장 시 함께 들어간다.
- 학생용 파일: 도구 막대에 `인쇄`만. 편집 없음.

## 7. check

1. 브라우저를 headless로 띄워 교사용(정답 켬)·학생용을 연다. `sheet.ready`를 기다려 `report()`를 받는다.

3. PDF 쪽을 PNG로 뽑아 `검사/학생-NN.png`, `검사/교사-NN.png`(150dpi). 모아보기 컬러·흑백 한 장씩.
4. 오류: 쪽 넘침(`overflow_mm > 0.5`), `too-tall`, 글자 칸 넘침, 깨진 그림, 수식 렌더 오류, 학생용에 `.ws-key`·`.ws-teacher-only`·`data-src`·`.ws-key-choice` 남음, 교사용 정답 문자열(4자 이상)이 학생용 HTML 원문에 있음, 외부 URL, 답 칸 7mm 미만, **손글씨 분량**: `key_text` 글자 수 × 4.5mm ÷ (칸 폭 − 3.6mm)를 올림한 줄 수 × 8mm + 2mm가 칸 높이보다 큼(`text` 칸만).
5. 경고: 학생 쪽 채움이 마지막 쪽이 아닌데 95% 미만 또는 99.5% 초과, 마지막 쪽 90% 미만, 늘이기 전 채움(`base_fill`)이 마지막 쪽에서 50% 미만, 내장 글꼴 미적용, 손글씨 분량이 칸 높이의 85% 이상.
