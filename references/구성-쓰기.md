# 구성.json 쓰기

1. `sheet.py new "<폴더>" --title "제목" --kind 수업 --columns 1`로 틀을 만든다. 각 명령 앞에 `python -X utf8 "<스킬>/scripts/sheet.py"`의 파이썬 호출을 붙인다.
2. `〔작성〕` 자리를 바꾸고 `items[].blocks`에 필요한 블록을 넣는다. 아래 예시는 블록 한 개씩 붙이는 조각이다. 정확한 필드·필수 여부·글자 한도는 `blocks <종류>`에서 확인한다(정본: `assets/kit/blocks.json`).
3. `plan "<폴더>"`에서 오류가 0이 될 때까지 원고를 고친다. `build "<폴더>"`로 두 HTML을 만든 뒤 `check`로 지면을 확인한다. 브라우저에서 저장한 편집을 배부본에 반영할 때는 `derive "<제목> (교사용).html"`을 쓴다.

## 문서 구조

```json
{
  "version": 1,
  "meta": {"title": "점의 위치", "kind": "수업", "columns": 1, "unit": "좌표평면", "goal": "점의 위치를 좌표로 설명한다."},
  "items": [{"id": "q1", "blocks": [
    {"type": "question", "text": "좌표를 쓰시오."},
    {"type": "answer", "rows": [{"label": "좌표", "lines": 3, "answer": "$(2,3)$"}]}
  ]}],
  "teacher": {"memo": ["풀이에서 가로 좌표를 먼저 쓰는지 확인한다."], "solutions": [{"item": "q1", "answer": "$(2,3)$"}]}
}
```

- `meta`: `title`은 파일명 기준, `kind`는 `수업`(기본)·`연습`·`평가`, `columns`는 `1`(기본) 또는 `2`. 화면 풀이 관련 `interactive`·`reveal`·`theme`·`accent`는 아래 "화면에서 푸는 활동지" 절. 자동 머리표에 `subject`, `grade`, `term`, `unit`, `header_title`(제목 덮어쓰기), `name_fields`(이름표 항목 1~3개), `pair`(수업 머리표에 짝 행)를 쓸 수 있다. `goal`은 화면에 표시하지 않는다. `total_points`가 숫자이면 답안 라벨 배점의 합과 일치해야 한다.
- `items[]`: 같은 쪽·단에 있어야 하는 블록을 한 item으로 묶는다. `id`는 영문·숫자·`-`로 겹치지 않게 쓰고 `head`는 자동 머리표에 남겨 둔다. `break: true`는 해당 item을 새 쪽(2단은 새 단)에서 시작한다.
- `teacher`: `memo`는 문단 배열, `solutions`는 `item`(item id), `answer`와 선택 배열 `steps`, `rubric`, `alternatives`, `misconceptions`. 번호가 붙은 발문마다 대응 풀이를 둔다. 교사 메모와 풀이는 학생용 HTML에 들어가지 않는다.

## 블록 고르기

| 종류 | 필드와 예시 |
| --- | --- |
| `notice` | `label`, `lines`(문단 배열). `{"type":"notice","label":"평가 안내","lines":["답과 풀이를 모두 쓰시오."]}` |
| `nameband` | `label`. 두 장째 이름 띠가 될 item에 `break: true`를 준다. `{"type":"nameband","label":"좌표평면 · 2장"}` |
| `situation` | `lines`; `title`, `figure`(그림 객체), `note`는 선택. `{"type":"situation","title":"<상황>","lines":["두 점의 위치를 비교합니다."]}` |
| `question` | `text`, `number`(생략하면 `true`). `{"type":"question","text":"점 $A$의 좌표를 쓰시오."}` |
| `answer` | `rows`에 답안 행 객체. `{"type":"answer","rows":[{"label":"좌표","lines":3,"answer":"$(2,3)$"}]}` |
| `steps` | `columns`(제목 배열), `rows`(행 수 1~20), `answers`(행×열 배열), `lines`(기본 2). `{"type":"steps","columns":["한 일","결과"],"rows":1,"answers":[["가로 확인","$2$"]]}` |
| `choices` | `options`(2~20개), `answer`(1부터 센 번호 또는 번호 배열), `cols`(한 줄에 놓을 개수). `{"type":"choices","options":["$1$","$2$"],"answer":2}` |
| `table` | `header`, `rows`(행×열 배열), 선택 `widths_mm`(열별 mm). `{"type":"table","header":["항목","값"],"rows":[["가","{{|$3$}}"]]}` |
| `figure` | 그림 객체의 필드를 `type`과 같은 단계에 둔다. `{"type":"figure","src":"그림/좌표.png","width_mm":55,"alt":"원점과 두 점","caption":"좌표평면"}` |
| `figures` | `items`에 그림 객체 두 개, 각 `caption` 필수. `{"type":"figures","items":[{"src":"그림/가.png","width_mm":50,"alt":"첫 그림","caption":"가"},{"src":"그림/나.png","width_mm":50,"alt":"둘째 그림","caption":"나"}]}` |
| `grid` | `mode`, `unit_mm`; `square`는 `cols`·`rows`, `coord`는 `x`·`y`, 선택 `labels`·`draw`. `{"type":"grid","mode":"square","cols":8,"rows":6,"unit_mm":5}` |
| `ask` | `tag`, `text`, `lines`, `answer`, 선택 `grow`. `{"type":"ask","tag":"<질문 1-1>","text":"어느 사분면인가요?","lines":4,"answer":"제1사분면"}` |
| `text` | `text`. `{"type":"text","text":"좌표를 비교해 봅시다."}` |

**답안 행**: `label`과 `answer`를 넣는다. `mark`는 같은 item의 상황·발문에서 쓴 빈칸 기호, `points`는 배점, `guide`는 라벨 아래 안내다. `lines`는 2~30(기본 3)이고 `grow: true`는 남는 높이를 답 칸에 나눠 준다. `kind: "draw"`인 행은 `height_mm`를 쓰고 `answer`에 문장 또는 그림 객체를 둔다. 이어 붙일 행은 같은 `group`을 주고 첫 행에만 라벨·배점을 적는다. `answer`는 모든 행에 넣는다.

**그림 객체**: `src`(활동지 폴더 안의 로컬 상대 경로, PNG/JPEG/WebP/GIF/BMP/SVG)와 `alt`, 또는 `svg`(독립된 SVG 문자열)를 쓴다. 양쪽 모두 `width_mm` 필수, `caption`·`teacher_only` 선택. SVG는 도형·글자·내부 정의만 쓰고 외부 그림, 스크립트, 외부 스타일은 넣지 않는다. `teacher_only: true`인 그림과 캡션은 학생용에서 제거된다.

**좌표평면**: `x`, `y`는 각각 정수 `[최소, 최대]`. 함수는 `{"fn":"2*x","teacher":true}`, 점은 `{"points":[[2,4]],"on":0,"names":["$P$"]}`처럼 `draw` 배열에 넣는다. `on`은 같은 `draw` 배열에서 검산할 함수의 위치(0부터)다. 수식에는 `x`, 수, 괄호, `+ - * / **`만 쓴다. `teacher: true` 그래프나 점은 학생용에서 사라진다.

## 화면에서 푸는 활동지

학생용 HTML을 열면 **풀기 화면**(휴대폰·태블릿에서도 한 줄로 읽히는 화면)이 나오고, 학생이 빈칸·답 칸·표 칸에 직접 쓰고 선택지·O·X·짝짓기·순서·점 찍기를 한 뒤 `확인`으로 맞았는지 본다. `A4로 보기`·`인쇄`는 지금까지와 같은 A4 쪽이다. 입력은 그 기기에 자동 저장되고, `답을 넣어 저장`으로 답이 든 파일을 내려받아 제출할 수 있다.

| meta 필드 | 값 | 기본 |
| --- | --- | --- |
| `interactive` | `true`면 학생용에 입력·정답 확인을 넣는다 | `수업`·`연습` `true`, `평가` `false` |
| `reveal` | `"시도 후"`(답을 쓰고 확인한 칸의 정답, 문항의 응답 칸을 다 채운 뒤 풀이) · `"바로"`(자습용) · `"교사만"`(맞음/틀림만) · `"없음"`(입력만, 제출용) | `"시도 후"` |
| `theme` | `"산뜻"`(색·아이콘·카드, 흑백 인쇄 가능) · `"정본"`(흑백 양식) | `수업` `"산뜻"`, 그 밖 `"정본"` |
| `accent` | `"하늘"` · `"민트"` · `"주황"` · `"보라"` | `"하늘"` |
| `sync` | `false`면 이 활동지에서 학생 기록 전송을 끈다 | 설정이 있고 화면 풀이가 켜진 경우 자동 연동 |
| `sheet_id` | 소문자·숫자·`-` 1~32자로 된 활동지의 고정 식별자 | `new`가 생성. 없으면 연동 조립 시 제목 해시를 쓰고 경고 |

교사 설정과 개인정보 안내는 [README](../README.md)의 학생 기록 연동 설정을 따른다. 같은 활동지의 기록을 계속 보려면 제목을 바꾸더라도 생성된 `sheet_id`는 유지한다. `sync: false` 또는 `interactive: false`면 연동 메타가 들어가지 않는다.

**자동 판별은 도구가 정답에서 정한다.** 빈칸·답 칸의 정답이 수(`$-3$`, `$\\frac{1}{2}$`, `7000원`, `$x=2$`)면 수로 비교한다: 공백·`+`·쉼표·앞의 `x=`를 무시하고 `0.5`와 `1/2`를 같게 본다. 단위는 학생이 쓰지 않으면 따지지 않고, 쓰면 정답의 단위와 같아야 한다(정답 `2분`에 `2`·`2분`은 맞음, `2시간`은 틀림). 수가 아닌 짧은 빈칸(12자 이하, 예 `꼬인 위치`)과 `"check": "text"` 답 칸은 공백·대소문자를 무시한 글자 비교이고, 등호가 하나인 식은 좌우를 바꾼 꼴도 맞게 본다(`y=2x`와 `2x=y`). 글 답이 예상과 다르면 ‘틀림’이 아니라 ‘확인 필요’로 표시된다(같은 뜻의 다른 표현을 도구가 다 알 수 없기 때문이다). 그 밖의 답 칸(설명·서술)은 자동 판별하지 않고, 학생이 쓴 뒤 예시 답안·채점 요소와 스스로 비교한다.

- 다르게 써도 맞는 답이 있으면 빈칸은 `{{㉠|$5$;;다섯}}`처럼 `;;`로 잇고(첫째가 교사용 표시), 답안 행은 `"accept": ["…"]`. 교과서 표기 약속에 어긋난 꼴(곱셈 기호를 생략하지 않은 `y=2×x` 등)은 넣지 않는다.
- 식을 쓰는 답 칸은 정답이 수가 아니어서 기본으로는 판별하지 않는 서술 칸이 된다. 자동 판별하려면 `"check": "text"`를 준다. 판별을 끄려면 `"check": "off"`.
- 선택지는 `answer`가 배열이면 여러 개 고르기. 표의 빈칸(`{{|$3$}}`)도 칸마다 입력·판별된다.
- 정답·풀이는 학생용 파일 안에 **해시와 난독화**로만 들어간다. 소스 보기로 바로 보이지는 않지만 보안은 아니다(개발자 도구를 쓰면 풀 수 있다). 점수가 걸린 평가는 `interactive: false`(기본) 또는 `reveal: "없음"`으로 둔다.

| 종류 | 필드와 예시 |
| --- | --- |
| `heading` | 활동 제목 띠. `tag`, `text`, 선택 `icon`(`pencil` `bulb` `search` `check` `video` `chart` `puzzle` `star` `warn` `book` `calc` `flag`), `image`(그림 객체, 폭 30mm 이하). `{"type":"heading","tag":"활동 1","text":"규칙 찾기","icon":"search"}` |
| `callout` | 개념·생각·주의·정리·예시 상자. `kind`, `lines`(빈칸 가능), 선택 `title`·`image`. `{"type":"callout","kind":"개념","title":"일차함수","lines":["$y=ax+b$ 꼴로 나타낼 수 있는 함수"]}` |
| `split` | 좌우 나눔. `left`·`right`(블록 배열), 선택 `ratio`(`"1:1"` `"2:1"` `"1:2"` `"3:2"` `"2:3"`). 안에 `split`을 또 넣거나 `columns: 2`와 함께 쓰지 않는다. `{"type":"split","ratio":"3:2","left":[…],"right":[…]}` |
| `ox` | O·X. `items`에 `{text, answer: "O"|"X"}` 1~10개. `{"type":"ox","items":[{"text":"$0$은 양수이다.","answer":"X"}]}` |
| `match` | 짝짓기. `left`·`right`(같은 길이 2~8, 같은 순번끼리 정답 짝 — 화면에서는 오른쪽을 섞어 보인다), 선택 `prompt`. |
| `order` | 순서 맞추기. `items`(올바른 순서 2~8 — 화면에서는 섞어 보인다), 선택 `prompt`. 인쇄본에는 ‘□ 안에 순서대로 1, 2, 3, …을 써 봅시다.’(`수업`) 또는 ‘□ 안에 순서대로 1, 2, 3, …을 쓰시오.’(`연습`·`평가`) 안내가 붙는다. 발문·`prompt`는 ‘순서대로 정리해 봅시다’처럼 화면·종이 모두에 맞게 쓴다. |
| `flow` | 상자와 화살표 도식. `nodes`(2~8, 빈칸 가능), 선택 `arrows`(화살표 위 글자, 길이 = nodes − 1). |
| `numberline` | 수직선. `range: [a,b]`, `step`, 선택 `labels`·`points:[{x,name}]`·`width_mm`, 학생이 점을 찍게 하려면 `plot: {"answer":[x…], "snap":0.5}`. |
| `grid` | 1판 필드 + 점 찍기 `plot: {"mode":"points","answer":[[x,y]…]}` 또는 직선 긋기 `plot: {"mode":"line","answer":"2*x+1"}`(두 점을 찍으면 직선), 자유 그리기 `pen: true`. |
| `chart` | 통계 그래프(계산해서 그림). 자료·통계를 다루는 문항에 쓰고 함수 관계를 막대로 나타내지 않는다. `kind`: `bar`·`line`(`labels`+`values`), `histogram`·`polygon`(`bins` 경계값 n+1개 + `values` n개), `scatter`(`points`+`x`+`y`). 선택 `x_label` `y_label` `y_max` `y_step` `width_mm` `height_mm`. `teacher: true`면 막대·점을 교사용에만(학생은 빈 축에 그림), `plot: {"answer":[…]}`(bar·histogram)이면 학생이 막대 높이를 눌러 정한다. |
| `explore` | 슬라이더 탐구. `fn`(예 `"a*x+b"`), `params:[{name,label,min,max,step,value}]` 1~3개(건너뛸 값은 `except`, 예 정비례의 a는 `[0]`), `x`·`y`(범위), `unit_mm`, 선택 `table:[x…]`(값 표)·`prompt`·`print`. `print:[{"a":2},{"a":-2}]`(최대 4개)를 주면 인쇄본에 그 값들의 그래프와 표가 나란히 나온다. 없으면 인쇄에는 처음 값의 그래프 하나뿐이므로, 값을 바꿔 비교하게 하는 문항에는 `print`를 준다. `label`은 `$a$의 값`처럼 수식·강조 표기를 쓸 수 있다(빈칸은 넣지 않는다). 생략하면 매개변수 이름을 수식으로 쓴 ‘$a$의 값’이 표시된다. |
| `video` | 영상. `url`(YouTube) 또는 `src`(폴더 안 mp4, 20MB 이하), `title`, 선택 `start`(초)·`caption`. 화면에서 눌러야 불러오고, 인쇄에는 제목·주소가 나온다. **사용자가 준 주소나 직접 확인한 주소만 쓴다.** |
| `checklist` | 화면에서만 보이는 스스로 점검. `items`, 선택 `title`·`print`(`true`면 인쇄에도). `평가`에는 쓰지 않는다. 점검 문장에 앞 문항의 답(‘원점을 지나는지’ 등)을 쓰지 않는다. |

- item에 `"hints": ["…", "…"]`(1~3개)를 주면 풀기 화면에 `힌트 1`, `힌트 2` 단추가 생긴다(인쇄에는 없음). 힌트는 다음 생각으로 이끄는 질문이며 정답을 말하지 않는다.
- `teacher.solutions[]`에 `"video": {"url": "…", "start": 0}`를 주면 풀이 보기 안에 풀이 영상이 나온다.
- 그림 에셋(상황 삽화·스티커·선 그림)은 `sheet.py art "<폴더>" <id> --kind 장면|스티커|선화 --prompt "…"`로 만들어 `그림/<id>.png`를 그림 객체로 넣는다. 그림에 문제의 수·조건·정답·글자를 넣지 않는다. 수학 도형·그래프는 `grid`·`numberline`·`chart`·`figure.svg`로 계산해서 그린다.

## 표기와 자주 하는 실수

- 수식은 `$…$`: `$A$`는 점의 정체 이름, `$\mathit{A}$`는 평면 이름처럼 영문 한 글자를 기울임으로 표시한다. JSON 문자열에서 명령의 역슬래시는 두 번 쓴다(`"$\\mathit{A}$"`, `"$\\frac{1}{2}$"`).
- `**굵게**`는 굵게, 한 개 `*`는 그대로 표시한다. 글자 자체인 `$`, `{`, `\`에는 표기에서 각각 `\$`, `\{`, `\\`를 쓴다(JSON에서는 각 역슬래시를 한 번 더 이스케이프).
- `{{㉠|꼬인 위치}}`, `{{|$3$}}`, `{{|$3$|30}}`: 기호+정답, 기호 없는 정답, 너비 30 mm 지정. 렌더러는 `{{㉠}}`도 읽지만 배부 원고에서는 정답이 빠져 `plan` 오류가 난다. 기호는 `㉠`, `㉡` 순서대로 이어 쓴다. 밑줄 문자를 연달아 쓰거나 표의 빈 칸을 빈 문자열로 두고 정답 칸으로 쓰지 않는다.
- 빈칸 너비를 생략하면 정답과 대안 정답 중 가장 긴 평문(수식·강조 표기를 실제 글자 표현으로 바꾼 것)을 기준으로 글자당 4.5mm를 잡는다. 최소 너비는 기호가 있으면 9mm, 없으면 18mm다. 한 `table` 안에서는 지정 너비도 포함해 가장 넓은 빈칸에 모두 맞추되, 표 칸 밖으로 넓히지는 않는다.
- 한 문자열은 한 문단이다. 줄을 바꾸려면 필요한 블록·문단 배열을 쓴다. 문항 번호는 도구가 붙인다. 답 칸에 그대로 옮겨 쓸 수 있는 분량의 정답을 쓰고, 긴 해설은 `teacher.solutions`로 옮긴다.
- 답을 학생이 읽는 본문이나 공개 그림·대체 설명에 직접 쓰지 않는다. 도구는 계약의 교사 표시를 지우며, 평문으로 섞여 들어간 답을 추론해서 지우지는 않는다.
